# Multivalent recombinant E2 vaccine against BVDV-1: immunogenicity and challenge in calves

Data and R scripts for the manuscript *Immunogenicity and Post-Challenge Virological and Clinical
Outcomes of a Multivalent Recombinant E2 Subunit Vaccine Against Four BVDV-1 Subgenotypes in Calves*.

## Structure

```
data/raw/          original spreadsheets (not included)
data/processed/    clean data used by the analysis scripts
R/                 analysis scripts
results/figures/   figures generated by the scripts (PDF, TIFF 600 dpi, PNG)
results/tables/    one Excel file of results per script
results/reports/   one Word report per script
results/models/    fitted models (.rds)
results/manuscrito/Figuras_editadas/   final figures of the manuscript
```

## How to run

Open `Manuscrito-BVDV-challenge.Rproj` in RStudio and run the scripts in this order:

1. `00_Limpieza_datos_clinicos.R` (only if the original spreadsheets are in `data/raw/`)
2. `Curso_temporal_Igg.R`, `Analisis_Estimulacion.R`, `Seroneutralization.R`,
   `Ciquinas_desafio.R` and `Viremia.R` (any order)
3. `Temperatura_linfocitos.R` (saves Figure 8A-B panels)
4. `Dirrea.R` (assembles the complete Figure 8)
5. `Signos_clinicos_score_post_desafio.R` (writes the clinical AUC table used in step 6)
6. `Correlaciones.R`

Each script installs missing packages, reads from `data/processed/` and writes to `results/`.
Package versions used are recorded in `results/sessionInfo_*.txt`.
